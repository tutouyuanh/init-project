# 西游冒险

Godot 4.x 俯视角近战动作 Roguelike，已接入 AI 生成场景与角色素材，无第三方运行依赖。

当前像素风版本：主角使用新生成的四帧行走图集，小妖使用 SpriteCook 官方 CC0 的八帧待机、行走、攻击图集。场景保留西游背景，以3像素网格与限色后处理统一观感，文字界面单独渲染。背景尚未重画为原生像素 tileset，Boss 仍沿用已有造型。

移动每走24单位触发扬尘，闪避生成短暂角色残影。挥击增加高对比拖尾，普通命中与重击分别触发像素爆点，重击追加外围碎片；原有命中停顿、击退和音效保留。所有地面特效使用世界坐标，不会跟随角色一起滑动。

## 运行

使用 Godot 打开 `project.godot`，按 **F5** 运行项目。主场景为 `scenes/main.tscn`。建议窗口比例 16:10；默认窗口 1280×800，逻辑画布 1440×900。

- WASD：移动；鼠标：控制近战朝向。
- 左键或 J：三段连击，可按住连续出招；第三段扩大范围并增加伤害和击退。
- 右键或 K：重击，伤害2.8倍，较长前摇，冷却2.8秒。
- 空格：闪避，冷却1.6秒，短暂无敌，可以取消攻击动作；没有移动输入时向鼠标方向闪避。筋斗云延长腾云时间。
- Tab：宝物背包及当前属性，同时暂停。
- Esc：暂停、继续或返回角色选择。
- E：击败 Boss 后靠近地图金色法阵，打开过关界面；点击“进入下一关”或再次按 E 切换场景，最终关完成结算。
- 宝物靠近自动吸取。右下角为房间、敌人、人物和出口的小地图。

## 已实现

四位角色及专属天赋，3 档掉落概率，4 档初始难度；18 种宝物及重复叠层、复合加成、溅射、击退、击杀回复、真视、灼烧、复活、腾云、减伤、随机复制。

依次挑战东海龙宫、女儿国、火焰山、天庭、盘丝洞、大雷音寺。每关生成六个随机大小和位置的房间及连接走廊；敌人通过路径图绕墙追击。前五关三波小怪后出现 Boss，最终关两波后出现如来。敌人使用有地面预警的近身攻击，Boss 使用大范围砸地，牛魔王附带冲锋。不再使用子弹或弹幕。清场后出现出口，胜负均可重新开始。

近战有前摇、有效攻击和收招三个阶段，扇形范围受墙体阻挡。每次挥击对同一敌人只结算一次。命中停顿35ms，重击或终结段75ms，配合击退、硬直、闪白、火花、镜头震动和合成音效。小怪的攻击前摇可打断；Boss 有抗击退能力。闪避与击退采用分步移动碰撞。

## 数值口径

六关按“东海龙宫 → 女儿国 → 火焰山 → 天庭 → 盘丝洞 → 大雷音寺”依次轮换，一次只显示当前关卡主题。`assets/stages/` 中有六个独立场景纹理资源，分别引用原始图集的独立区域；原始图集仅作为美术源文件，不作为六场景拼图展示。过关界面暂停战斗和计时，换关清理旧地图、敌人和掉落，保留角色、已拾取宝物及属性。

- 宝物数量无限，线性叠加到效果上限后继续记录数量。
- 攻击、攻速、移速、生命最高是角色初始值的 **300%**，即最多 +200%。角色天赋计入封顶前的加成。
- 暴击率使用绝对百分点，上限 300%。100% 为必定一重暴击，150% 为必定一重且有50%概率额外一重，300% 为必定三重。每重增加100%基础伤害，孙悟空增加150%。
- 回复以初始最大生命为基数。灵芝每秒回复2%初始生命，玉净瓶3%；回复上限为每秒300%初始生命。初始自动回复为0。
- 猪八戒每个宝物层数额外 +2% 初始生命。提高生命上限时同时增加相应当前生命。
- 金箍棒碎片每层溅射20%本次伤害，上限300%；击退每层15%概率，上限100%；击杀回复每层2%初始生命，上限300%；火焰每层每秒25%攻击伤害，上限300%。
- 真视扩大隐身怪物的可见范围，并在小地图显示隐身怪。宝物本身不隐身。
- 金刚不坏每层减伤20%，本原型例外封顶80%，避免完全免疫伤害。
- 九转金丹每层独立增加一次复活机会；复活消耗机会，保留宝物属性。
- 七十二变随机增加一个已拥有的非七十二变宝物层数，包括其特殊效果。没有符合条件的宝物时仅保存七十二变自身层数。
- 所有新宝物只来自怪物死亡的随机掉落，Boss 也使用所选掉落概率，没有商店或保底赠送。品质权重为白66%、蓝23%、紫9%、橙2%。复制属于既有宝物效果。
- 初始难度生命/攻击倍率为0.7、1、1.4、1.9；关卡倍率为1 + 关卡索引 × 0.35。
- 每180秒增加一档：时间生命倍率1 + 档数 × 20%，攻击倍率1 + 档数 × 15%；场上敌人同步按比例强化，之后每波额外增加2只怪物。暂停不计时。

## 工程结构与验证

- `scripts/game_data.gd`：角色、关卡、宝物配置。
- `scripts/main.gd`：界面、地图碰撞、宝物、流程与结算。
- `scripts/melee_combat.gd`：连击、重击、闪避、敌人近战、命中反馈与音效。
- `scripts/world_art.gd`：背景、地面、视差、角色和前后遮挡。
- `scripts/pixel_fx.gd`：像素扬尘、残影和命中爆点。
- `assets/spritecook/`：实际使用的官方 CC0 动画图集和许可，来源见 `SOURCES.md`。
- `assets/art/`：生成图集；提示词与生成方式见 `PROMPTS.md`。
- `tests/smoke.gd`：核心玩法断言，含48张地图连通与六关流程。
- `tests/melee.gd`：近战范围、前摇、单次命中、连击、闪避取消、重击冷却、墙体和敌人预警。
- `tests/stage_rotation.gd`：六个独立场景依次切换、过关暂停、宝物保留和最终结算。
- `tests/live_input.gd`：实际输入分发、帧循环攻击击杀、暂停与闪避。
- `tests/pixel_fx.gd`：移动特效、残影、重击爆点、动画资源与特效生命周期。
- `tests/preview.gd`：启动图形窗口，生成菜单、战斗与各场景截图。

macOS 本机验证命令：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/smoke.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/melee.gd
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/live_input.gd
/Applications/Godot.app/Contents/MacOS/Godot --path . --script tests/preview.gd
```

已使用 Godot 4.7.2 验证。环境借鉴用户指定《雨中冒险 2》的地形、远景和地标层次，仍为2D玩法。六场景与角色使用内置 image_gen 生成并实际接入，未复用参考游戏素材；工具不提供指定“GPT 2.5 image”的参数。完整提示词与底色处理说明见 `assets/art/PROMPTS.md`。

主角已接入生成的四帧行走循环，攻击仍由姿态变化与独立武器轨迹驱动，尚无完整方向动画或骨骼动画。小妖已接入八帧动画；六个 Boss 尚未全部拥有独立美术与完整招式组。音效为程序合成，尚无配乐、存档或局外成长，也未进行完整平衡性测试。
